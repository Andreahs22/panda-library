# Panda Library

Sitio web estático de una librería ficticia de Buenos Aires, hecho como pre-entrega del proyecto de Front-End.

## Propósito

Mostrar un catálogo de libros, reseñas de lectores, un video sobre la lectura y un formulario de contacto.

## Contenido

- **HTML semántico:** `header`, `nav`, `main`, `section` y `footer`.
- **Productos:** cards con Flexbox.
- **Reseñas:** distribución con Grid.
- **Contacto:** formulario con [Formspree](https://formspree.io) y diseño responsive con media queries.
- **Multimedia:** portadas de los libros, logo en SVG y un video de YouTube embebido.
